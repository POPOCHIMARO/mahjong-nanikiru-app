## 解釈と検証の限界

手役はmahjong 2.0.0で最高点分解を再判定する。リーチ、ツモ、場風、自風、ドラ、赤、裏、暗槓を入力し、連風対子2符と数え役満なしを適応。
一発、ダブルリーチ、海底、河底、嶺上、槍槓は手役ランキングに含めず、これらの時系列判定や全点数の一致検証は行っていない。
多分解の和了はsummaryのqualityに数える。役の選択は状況役を指定しない再判定結果であり、公式の役記録と同一とは保証しない。
独立検証は原牌譜から全和了の手牌と裏枚数を再計算する。役ラベルの意味的判定は分析側ライブラリに依存し、役別集計の分母と計算を検算する。
Wilson95%区間は和了を独立試行とみなす近似で、牌譜の訂正や選手内相関、公式全試合との網羅性を保証する区間ではない。
実測率は取得データの記述統計。特定の牌姿、選手、未来の対局での確率や、手役を狙う戦術の優劣を保証しない。

数値と解釈は `wiki/研究ノート/リーチ和了の裏ドラ率と手役.md` に保存。

訂正snapshotがある場合は `../ingest/2026-10-12.paifu-corrections.jsonl` を試合URLと局索引で優先読取する。旧原本は不変。訂正14局のうち分析上の裏表示が変わった4和了と旧新集計を `correction_impact.json` に保持した。
