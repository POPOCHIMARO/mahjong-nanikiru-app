# リーチ和了の裏ドラ率と手役

対象期間: 2018-19〜2026-27シーズン、2018-10-01〜2026-10-06の取得済み公開牌譜。
取得日: 2026-10-12。
対象は第三者の[Mリーグ牌譜サイト](https://m-league.konoui.dev/)で公開された範囲であり、公式の全試合を保証する母集団ではない。

## リーチ和了で1枚以上乗る率

**計算結果**: 裏ドラが1枚以上乗る率は **32.20%（3,230 / 10,030和了）**。
裏表示牌が1枚の場合は **31.13%（2,969 / 9,538和了）**。
槓裏を含む全体では、およそ3回に1回となる。

| 条件 | 裏1枚以上 | 裏を確認できた和了 | 率 | Wilson95%区間 |
|---|---:|---:|---:|---:|
| 全リーチ和了 | 3,230 | 10,030 | 32.20% | 31.30〜33.12% |
| 裏表示牌1枚 | 2,969 | 9,538 | 31.13% | 30.21〜32.06% |
| 裏表示牌2枚以上 | 261 | 492 | 53.05% | 48.63〜57.42% |
| 役満を除く | 3,227 | 10,017 | 32.21% | 31.31〜33.14% |

和了10,044件のうち、裏表示が欠けた14件は主率の分母から除いた。
全14件が裏0と仮定すると32.16%、全14件が裏ありと仮定すると32.30%であり、今回の欠損による範囲は小さい。
役満13件も、リーチして和了したという主定義には含めた。
ここでの「乗る」は手牌に裏ドラ該当牌があることを意味し、役満の得点をさらに増やす意味ではない。

分母は和了したリーチ者であり、全リーチや全局ではない。
この値に和了率を掛けずに「リーチしたら32%で裏ドラを獲得する」と読むことはできない。
Wilson区間は独立試行を仮定した近似で、データの訂正や選手内相関を含む保証範囲ではない。

## 手役別に乗る率

分母は「その役を含む、裏表示の分かるリーチ和了」全件。
裏が乗らなかった和了も含める。
主表はサンプル100和了以上の手牌役とし、裏表示が1枚の条件でも比較する。
一和了には複数の役があるので行同士は重複する。

| 再判定した手牌役 | 裏あり / 和了 | 裏1枚以上の率 | 裏表示1枚に限定 | 平均牌種類数 |
|---|---:|---:|---:|---:|
| 一気通貫 | 48 / 136 | 35.29% | 34.33%（46 / 134） | 12.65 |
| 平和 | 1,276 / 3,724 | 34.26% | 33.52%（1,215 / 3,625） | 12.05 |
| 断么九 | 511 / 1,603 | 31.88% | 30.86%（469 / 1,520） | 10.91 |
| 役牌 | 224 / 777 | 28.83% | 27.09%（194 / 716） | 9.95 |
| 三色同順 | 99 / 352 | 28.12% | 27.94%（95 / 340） | 12.36 |
| 一盃口 | 174 / 626 | 27.80% | 27.42%（164 / 598） | 9.25 |
| 七対子 | 102 / 462 | 22.08% | 20.63%（91 / 441） | 7.00 |

一気通貫が観測上の首位だが、136件であり平和との差は1.03ポイント。
半荘を単位とする2,000回のブートストラップでは、差の95%区間は−7.31〜9.05ポイントで、どちらが高いかは確定できない。
平和と七対子の差は12.19ポイントで、同じ方法の区間は7.86〜15.99ポイント。
これは観測した和了群の差であり、同じ手を特定の役へ変えたときの因果効果ではない。
シード20261012、半荘内の和了をまとめて再抽出し、複合役の重なりも保った。
比較は探索的で、全役を総当たりした多重比較の検定結果ではない。

門前清自摸和は1,743 / 5,263で33.12%（裏表示1枚なら31.98%）。
これは和了手段での分類であり、主表の手牌構造役とは分けた。
清一色は2 / 3（66.67%）、混全帯么九は11 / 25（44.00%）、三暗刻は17 / 50（34.00%）だった。
これらを「高確率な役」として優先するには例数が足りない。
全役の件数と区間は `data/mleague/ura_dora/summary.json` に保持した。

## 裏が乗った和了の手役内訳

これは「その役なら乗る率」と別の条件付き確率である。
裏あり3,230和了を分母にすると、平和を含むものは1,276件（39.50%）、断么九511件（15.82%）、役牌224件（6.93%）、一盃口174件（5.39%）、七対子102件（3.16%）、三色同順99件（3.07%）、一気通貫48件（1.49%）。
門前清自摸和を含むものは1,743件（53.96%）。
複合役があるため、これらの構成比を足して100%にすることはできない。
一気通貫は役別の乗る率が高めでも、そもそもの和了数が少ないので裏あり群の中では少数となる。

## 七対子の裏2枚

七対子で裏が乗った102件は、すべて2枚以上だった。
七対子の裏2枚以上率は22.08%（102 / 462）で、全リーチ和了の7.92%（794 / 10,030）より高い。
裏表示1枚に限ると七対子20.63%（91 / 441）、全体7.13%（680 / 9,538）。
七対子は「1枚以上乗りやすい」という性質と、「当たったときに2枚乗る」という性質を分けて考える必要がある。

全体の裏枚数分布は、0枚6,800件、1枚2,436件、2枚568件、3枚202件、4枚20件、5枚4件。
平均はリーチ和了1回あたり0.427枚。
裏あり率32.20%と平均0.427枚は異なる指標である。

## 牌種類数との関係

**牌の構成からの説明**: 裏表示が当たる対象は、和了手牌にある牌の種類で決まる。
七対子は7種類、一盃口は同じ順子を重ねるので種類が少なくなりやすい。
一気通貫は同じ色の1〜9をすべて含み、平和も順子の重複が少ないと牌種類が増える。
今回の主表は、この種類数の違いと整合する部分がある。
ただし三色同順のように種類数だけでは実測順位を説明しきれない例もあり、牌の偏り、複合役、待ち、槓、サンプル数が関係する。
「役そのものが裏表示牌を変える」という因果を主張する分析ではない。
[[裏ドラ]]に単純モデルの範囲を記した。

## 旧版との時点差

全1,968試合ページの局リンクと保存牌譜を照合し、局の追加漏れ0、掲載局の欠落0を確認した。
過去14局にサイト側の訂正があり、旧rawと既存正規化牌譜を保持したまま、取得日付きの訂正JSONLを優先読取した。
裏表示を補えたリーチ和了3件で未確認17件が14件に減り、裏あり件数は3,229から3,230に増えた。
他の1件も裏表示が変わったが裏枚数は同じで、今回のリーチ和了の牌姿と再判定した手役には変化がなかった。
旧集計は `pre_correction_summary.json`、差分は `correction_impact.json` に保持し、旧値を削除していない。

## 方法と検証

原資料23,939局、牌譜のある1,964半荘、掲載試合索引は1,968試合。
10月8日の4試合は結果ページだけで牌譜リンクがない。
取得監査は[[Mリーグ公開牌譜差分取得_要約]]を参照。

1. 和了者の捨牌列に `r` 宣言がある局を抽出。ダブルリーチも含む。
2. 配牌からツモを加え、捨牌を除く。`60` と `r60` はツモ切り。暗槓は4枚を別保存し、ロンでは放銃牌を追加。
3. 赤を通常5と同じ種類として、裏表示から数牌、風牌、三元牌の次順牌を求め、手中の枚数を合算。暗槓の4枚も数える。
4. 牌数14+暗槓数、各種類4枚以下を確認。裏表示欠損は未確認のまま残す。
5. `mahjong==2.0.0` で最高点分解の手牌役を再判定。連風対子2符、数え役満なし、赤、槓、風位を適応。
6. 別実装で全和了手牌と裏枚数を原資料から独立に再計算し、入力SHA-256と全集計を照合。

**制約**: 原資料には役名も裏枚数もないため、役は公式記録の転載ではなく再判定したラベル。
一発、海底、河底、嶺上、槍槓、ダブルリーチの状況役は再判定していない。
これらを指定せず最高点分解を選んでいるため、多分解の34和了では実際の採点分解と同じとは保証しない。
一発などを含む全翻数と全点数の一致は未検証。
牌譜に符が明記された和了の符は全件一致した。
独立検証の役別部分は、ライブラリが返した役ラベルの件数と率の検算であり、役ラベル自体の独立認定ではない。

再実行手順は `data/mleague/ura_dora/README.md`。
`tools/test_mleague_ura_dora.py` の7テスト、`tools/verify_mleague_ura_dora.py` の全和了照合はいずれもexit 0。
復元失敗0、符不一致0、裏表の表示枚数不一致0。
